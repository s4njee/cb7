# Format support

Support depends on whether a file is scanned by the server, read in the browser, or opened by the native reader.

## Server and browser

| Format | Ingest | Browser reader | Notes |
| --- | --- | --- | --- |
| `.cbz` | Yes | Yes | ZIP comic archive; requires 7-Zip tooling on the server. |
| `.cbr` / `.rar` | Yes | Yes | RAR comic archive; uses `unrar` or the configured 7-Zip fallback. |
| `.epub` | Yes | Yes | Reflowable or fixed-layout EPUB through the browser reader. |
| `.pdf` | Yes | Yes | pdf.js reader with range loading. |
| `.mobi` | Yes | Limited | Cataloged, but EPUB/PDF is preferred for browser reading. |
| `.cb7` / `.7z` | No | No | Use the native reader or repackage as CBZ for server ingest. |
| `.cbt` / `.tar` | No | No | Repackage as CBZ. |
| Loose image folder | No | No | Bundle pages into CBZ for the server. |

## Native reader

| Format | Local import | Local read | Notes |
| --- | --- | --- | --- |
| EPUB | Yes | Yes | MOBI/AZW3 are converted to EPUB during import. |
| PDF | Yes | Yes | Range-backed pdf.js reader, text search, and highlights. |
| CBZ | Yes | Yes | Pages and ComicInfo.xml are read on demand. |
| CBR | Yes | Desktop | Desktop Rust builds use native RAR extraction. |
| CB7 / 7z | Yes | Yes | Pure-Rust 7z extraction; encrypted archives are not bypassed. |
| Image folder | Yes | Yes | Direct images become comic pages; linked folders remain in place. |
| DRM-protected book | No | No | CB8 does not circumvent DRM. |

Image pages may be JPEG, PNG, GIF, WebP, AVIF, or BMP. Natural filename ordering means `page2` comes before `page10`.

For server archive requirements, see [Configuration](/configuration). For local storage behavior, see [Local-first library](/reader/local-first).
