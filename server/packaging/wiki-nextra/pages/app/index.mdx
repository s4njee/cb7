# The app

CB8 has a native Tauri reader and a browser client served by the CB8 server. The native reader is the offline-capable application; the browser client is the zero-install way to use a server library.

## Native reader

The native reader supports macOS, Windows, Linux, iOS, and Android from the [`reader/`](https://github.com/s4njee/CB8/tree/main/reader) directory. It can open a local shelf before any server is configured, then connect to a CB8 server for remote browsing and sync.

## Browser client

Open the server URL in a browser after installation. The browser UI provides library browsing, folder hierarchy, tags, collections, series navigation, comic/EPUB/PDF reading, server-side progress, and optional semantic ebook search.

## Connecting

The reader can connect by typing the server address, using LAN discovery when available, or pairing with a QR code. Guest browsing is supported when enabled by the server; authenticated users can persist progress and use account-scoped libraries.
