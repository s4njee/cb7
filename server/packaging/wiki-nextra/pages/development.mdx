# Development

CB8 has two active applications in this repository:

| Directory | Role | Main stack |
| --- | --- | --- |
| [`server/`](https://github.com/s4njee/CB8/tree/main/server) | Server, browser UI, worker, ingest, API | Node.js, Fastify, React, Postgres, pgvector |
| [`reader/`](https://github.com/s4njee/CB8/tree/main/reader) | Native local/remote reader | Tauri v2, Rust, React, TypeScript |
| `server/packaging/wiki-nextra/` | This static wiki | Next.js, Nextra, MDX |

## Web UI and server

```bash
cd server
pnpm install
pnpm typecheck
pnpm test
pnpm build:renderer
pnpm build:standalone
```

The server and worker share Postgres. The worker drains scan, metadata, and search jobs; starting only the API leaves queued work unprocessed.

## Reader

```bash
cd reader
pnpm install
pnpm typecheck
pnpm test
pnpm build
cd src-tauri
cargo test
cargo clippy --all-targets -- -D warnings
```
